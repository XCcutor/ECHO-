# ECHO 🎵

A Spotify-inspired music player built from scratch using HTML, CSS, and JavaScript.

## Features

- 🎵 Play songs from the playlist
- ▶️ Play / pause controls
- ⏮️ Previous and ⏭️ next song controls
- 🔄 Automatically plays the next song
- 🎚️ Interactive progress bar
- 🎧 Displays the currently playing song
- ✨ Animated music GIF while a song is playing
- 📱 Basic responsive styling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Setup

The song files are not included in this repository.

To use the music player:

1. Clone this repository.
2. Create a folder named `songs` in the project directory.
3. Add your own audio files to the `songs` folder.
4. Name the files exactly:

```text
song1.mp3
song2.mp3
song3.mp3
song4.mp3
song5.mp3
